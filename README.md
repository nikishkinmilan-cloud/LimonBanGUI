# LimonBanGUI

Paper-плагин (1.21.11, Java 21): HUD-меню бана игроков из спектатора + отображение анти-чит показателей над головами.

## Возможности
- Spectator + shift + ПКМ по игроку (право `limonban.admin`) → меню бана
- «Вызвать на проверку» — дублирует `acprov review <ник>`
- «Отправить в комнату проверки» — телепорт в изолированную зону, `/limonban room set|tp|return`
- «Забанить → Античит» — категории из `config.yml` (2.4 / 2.4.1 / 2.4.2), бан на 25 дней (свой temp-ban, `bans.yml`)
- Цифра уровня подозрения над головами всех игроков, видна только `limonban.admin`

## Сборка
```
mvn clean package
```
Готовый jar: `target/LimonBanGUI.jar`

## Настройка
1. `config.yml` — длительность бана, категории, пороги цвета
2. В `AntiCheatBridge.java` — привязать к реальному методу LimonAntiCheat, возвращающему уровень подозрения (см. TODO в файле)
3. В игре: `/limonban room set`, стоя в месте будущей комнаты проверки
